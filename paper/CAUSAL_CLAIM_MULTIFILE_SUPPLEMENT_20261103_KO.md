# 다중 파일 diff 중복 전달 수정 보충 실험 — LocalAI 1개 PR, 2026-11-03

공개 diff의 중복 전달을 고친 뒤 새 응답으로 비교했지만, **추가 판단·탐색에 따른 F1 개선은 확인되지 않았다.** 초기 판단은 두 양성 관측의 원인 내용을 모두 맞혔으나 위치·상태 검증에서 유효 보고로 인정되지 않았다. 동일 본문으로 추가 판단한 조건은 그 정답을 보류했고, 조회 조건은 최종 판단 전에 예산 입장 검사에서 막혔다. 추가로 수집한 본문이 실제 모델 입력에 전달된 경우는 없었다. 따라서 추가 본문을 읽은 뒤의 탐지 효과는 이번 결과로 평가할 수 없다.

이 문서는 `causal_claim_loop_multifile_fix_20261103` **V2 16개 논리 리뷰만** 집계한다. V1 결과와 합산하지 않았다. 완료 집계, 실제 비용, 실패 원형 목록을 함께 보존했다.

**대상과 비교 조건**

- A: 공개 diff와 초기 정적 본문을 받은 새 판단 1회. **Diff-only baseline은 아니다.** 초기 본문은 방향별 5,199/5,200 reference tokens다.
- B: A와 같은 초기 응답·본문에서 후속 검증과 최종 판단, 최대 2회 추가.
- C: 같은 시작점에서 모델의 질문을 실제 Go AST/LSP 도구로 조회하는 최대 2라운드와 후속 판단.
- D: C에 동일 허용 소스 풀의 BASE/HEAD SCIP 후보·질문 우선순위를 추가. 참조를 실제 호출·실행 증명으로 간주하지 않는다.

V2는 V1의 파일/snapshot별 근거 ID마다 전체 공개 diff를 반복하던 직렬화만 수정했다. 공개 diff는 한 번, 각 ID에는 해당 snapshot·파일·실제로 표시된 physical rows의 citation map을 제공한다. 소스 본문·예산·모델·프롬프트 의미·schema·판독 기준은 원형을 유지했다. 모델은 `gpt-5.6-sol`, reasoning `low`, 공통 상한은 논리 리뷰당 모델 3회 및 provider input+output 120,000 tokens, 소스 본문 union 12,000 reference tokens다. 입장 검사는 schema와 24,000 reference-token 여유를 포함한다. 서버 출력의 검증된 hard cap을 뜻하지 않는다. V2 실행에는 별도 source overlay가 없으며 V1의 소스·정답·인덱스는 경로와 SHA로 읽기 전용 재사용했다.
