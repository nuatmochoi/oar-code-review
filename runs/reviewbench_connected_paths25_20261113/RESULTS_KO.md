## 결과가 말해 주는 범위

FLAT은 A보다 정답표 밖 추가 정탐(novel TP)이 4→10으로 늘어 Augmented F1은 24.12→25.18%가 됐다. 그러나 gold 탐지는 45→43, 오탐은 1→5다. 재현율과 오탐을 함께 개선했다고 볼 수 없다. PATH는 FLAT의 gold 정탐 43개 중 31개를 유지하고 12개를 잃었으며 8개를 추가했다. GROUPED는 FLAT의 28개를 유지하고 15개를 잃었으며 11개를 추가했다.

세 조건 모두 기존 source prefix를 보존했지만 정탐은 보존하지 못했다. 원문 보존과 모델 판단 보존은 다른 측정 대상이다. GROUPED의 실제 요청 25쌍을 대조해 본문·관계·trace·위치 ID·schema가 동일하고 렌더링 순서 외에는 차이가 없음을 확인했다. 실제 순서가 바뀐 PR은 22/25개다. 나머지도 독립 모델 호출이므로 생성 변동이 포함된다.

공식 점수는 micro 집계다. Grounded precision은 gold와 매칭된 보고 중 TP 비율, recall은 gold 352개 중 탐지한 비율이다. 매칭되지 않은 보고는 Grounded precision에서 제외된다. Augmented는 추가 판독된 novel TP/FP도 반영한다. 표의 오탐은 matched FP와 novel FP의 합계다. 한 보고가 여러 gold를 덮을 수 있으므로 보고 개수와 gold 개수를 혼용하지 않는다.

## 다음 설계: 핵심을 보되 근거를 끊지 않기

우선 인용 범위 오류를 수정한 공통 토대에서, 동일 원문·동일 관계를 유지한 위치 목록 압축을 단독 비교한다. 오프라인 exact round-trip으로 catalogue 466,678→104,307 reference tokens, 기본 prompt 합계 1,525,261→1,162,890(23.76% 절감)을 확인했다. 추가 해독 지침·전체 최종 요청·실제 API 비용과 F1은 아직 검증하지 않았다.

그다음 큰 함수를 통째로 넣거나 버리는 선택을 완화한다. 변경 연산·값의 정의/대입·필요 분기·소비 연산을 실제 source 범위로 묶고, 빠진 조건과 전체 함수의 위치를 명시해 다시 조회할 수 있게 한다. 전체 후보 목록은 남기고 여러 변경 영역에 먼저 방문 기회를 주되, 예산 때문에 못 본 항목은 deferred로 표시한다. 요약·정의 위치·reference edge만으로 실행 경로를 확인했다고 처리하지 않는다.

후속 설계와 무손실 인코딩 진단. 후속 설계는 현재 동결 실행에 반영하지 않았으며 새 F1을 주장하지 않는다.
