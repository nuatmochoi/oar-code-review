¹ 기존 방식은 질문이 지정한 ID를 모두 제공했는지, 근거 묶음 방식은 질문에 명시한 모든 역할에 원문을 제공했는지 셌다. 답변 완료의 분모는 전체 질문이며, 원문을 모두 받은 뒤 리뷰 모델이 답할 수 있었다고 판정한 질문을 센다. 두 방식에서 별도로 질문을 생성했다. 원문의 의미와 공식 정답 일치는 모델이 판정했다. 사람의 검토는 0회다.

4,096토큰 출력 한도에 도달한 응답 4개는 모델을 다시 호출하지 않고 완전한 배열 항목만 복구했다. 끊긴 항목과 그 뒤의 항목은 집계에 들어가지 않았다. 이 4개 PR을 제외한 나머지 21개에서도 기존 다중 ID는 공식 정답 48개, 근거 묶음은 40개를 찾았다. 원시 출력과 복구 내역을 보존했다.

공식 채점은 체크포인트와 이전과 동일한 입력의 응답을 재사용해 25개 모두 마쳤다. 마지막 요청 1회의 채점 출력 상한을 16,384에서 8,192로 낮췄고 실제 출력은 588토큰이었다. 파일별 조회 결과가 일치하는 경우에 한해 파일 순서를 이전과 같게 복원했다. 채점 모델·프롬프트·집계 기준은 동일하다. 재개 과정의 지출도 표의 비용에 포함했다.

근거 묶음의 초기 후보 판정은 지지 42개, 수정 3개, 반박 0개, 보류 8개, 중복 0개였다. 수정안 3개가 초기 후보 ID에 연결됐고, 그중 1개가 최종 보고에 포함됐다. 공식 채점에서 그중 1개를 정탐으로 판정했다. 최종 추가 보고는 기존 39개, 근거 묶음 31개였다. 후보별 원문, 상위 후보, 원인 판정, 결합 결과는 각 PR의 기록에 남겼다.

복수 역할을 요청한 질문 432개 중 353개에서 모든 역할에 원문을 배정했고, 139개에서 답변까지 완료했다. 유효한 ID 힌트가 없었던 역할 99개 중 94개에 검색으로 원문을 제공했다. 힌트가 있었지만 그 밖에서 원문을 찾은 역할은 124개였다. 완료 질문 ID와 연결된 추가 보고는 23개였고 그중 17개를 공식 판독에서 정탐으로 봤다.

원문을 모두 받은 질문 중 212개는 여전히 근거가 부족하다고 판정됐다. 실패 분기 116개, 반증 86개, 구현 85개 질문에서 해당 역할이 부족하다고 모델이 기록했다. 한 질문에 여러 역할이 겹친다. 근거 묶음의 기계적 검사를 통과한 후보는 113개에서 90개로 줄었다. 공식 판독에서 추가 보고가 기존 gold에 일치한 건수는 20개에서 10개로 줄었고, gold 밖 정탐 보고는 11개에서 14개로 늘었다.

근거 묶음 방식만 찾은 공식 정답은 3개, 기존 다중 ID 방식만 찾은 정답은 13개였다. Grounded F1 차이의 PR 쌍 재표집 95% 구간은 -6.92~-1.50%p다. 같은 개발 PR에서 조건당 한 번 실행한 비교이며, 재실행 변동은 이 구간에 들어가지 않는다. 이번 실험은 역할 분해·의미 순위·묶음 조회·수정 추적을 함께 평가했다.

의미 검색은 질문과 역할마다 기존 원문 안에서 상위 3개를 순위화했다. 공통 원문은 두 방식의 마지막 리뷰 입력에도 들어간다. 순위는 앞선 검증 단계에서 어떤 원문을 읽고 조합하는지에 영향을 주며, 동일 심볼의 호출·구현·실패 경로가 실제로 연결되는지는 보장하지 않는다.
