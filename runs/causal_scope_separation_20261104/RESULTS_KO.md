## 구현과 실행 범위

아래 AST·LSP·route 기능은 두 재탐색 조건에 공통이다. 이번 변경은 확인된 원인/미확인 영향을 명시적으로 분리하고 재계획·최종 보고에 반영하는 단계이다.
- AST가 같은 함수 안의 유일한 실제 호출 토큰을 확인하고, 최대3행의 위치 오차를 보정한다. 복수 후보는 unresolved로 보존한다.
- 호출 구현 본문 요청은 LSP definition으로 실제 선언 URI/범위를 연결하고 완전본문·버전·해시를 기록한다. 검색 결과는 후보이며 다른 caller 본문을 callee 구현 확보로 승격하지 않는다.
- route 전체의 분류 오류는 그대로 남기되 고유한 현재 condition/pending challenge의 안전한 read를 차단하지 않는다. 과거·철회·중복·다른 snapshot 대상은 허용하지 않는다.
- 원시 질문·AST 좌표 보정·LSP RPC·본문·후보 변경·응답·실패는 새 디렉터리에 보존했다. 모델의 의미 판단과 기계적 연결 검사는 다르며 실제 runtime/probe는0이다.
