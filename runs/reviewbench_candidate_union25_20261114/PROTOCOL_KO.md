기존 의미 검색 결과의 25개 PR·BASE/HEAD·최종 보고 81개를 고정한다. 범위 확대와 후보 생성 개선에서 기계적 인용 검사를 통과한 후보와 해당 인용 범위를 재사용한다. 이전 모델의 후보 채택 여부와 공식 채점은 결합 모델에 제공하지 않는다. 원문과 인용이 동일한 후보는 출처를 합쳐 한 번만 보낸다. 기존 보고와 문구·위치가 같은 후보는 자동으로 제외한다. 사전 동결한 요청에서 결합 모델이 기존 보고 및 다른 후보와 원인 중복을 비교하고 원인·발생 조건·관찰 결과를 원문과 대조한다. 한 수정으로 해결되는 후보는 같은 결함으로 다룬다.

이전 두 조건과 동일한 확대 원문, 모델·추론 설정, 호출당 출력 4,096토큰, PR당 신규 200k토큰, PR당 새 보고 최대 3개와 전체 최대 6개를 적용한다. 모델 결합은 후보와 보고 자리가 있는 경우에 한 번 실행한다. 후보를 다시 생성하지 않는다. 기존 보고 81개는 문구·위치·순서를 유지한다. 후보가 인용한 코드에서 근거를 찾고 가능한 경우 가까운 반증을 확인한다. 방어적 정적 리뷰이며 익스플로잇 개발·재현·대상 실행을 포함하지 않는다.
