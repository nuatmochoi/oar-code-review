# 코드 리뷰 실험 기록

실제로 수행한 코드 리뷰 실험의 비교 조건, 평가 기준, 관측 결과를 모았다. 실행 실패와 성능이 개선되지 않은 결과도 포함한다.

ReviewBench 25개는 공개 개발용 세트다. 48개 비교 및 Python·Go 개발 사례의 자체 평가 점수는 공식 Grounded·Augmented F1과 평가 기준이 다르다.

실험별 실행·평가 코드는 결과 보고서와 같은 디렉터리에서 확인할 수 있다. 공통 리뷰 구현은 ace_review/에, 언어 분석과 실행 도구는 tools/에 있다.

대표 비교의 실행 흐름은 [입력 준비](runs/reviewbench_official25_context_ablation_20261117/prepare_inputs.py), [리뷰 요청과 저장](runs/reviewbench_official25_context_ablation_20261117/experiment.py), [리뷰·채점 실행](runs/reviewbench_official25_context_ablation_20261117/run.py), [결과 집계](runs/reviewbench_official25_context_ablation_20261117/report.py)에서 확인할 수 있다.

**재실행 지원 범위는 공식 25개 PR의 Diff → AST → LSP 비교다.** [재실행 안내](runs/reviewbench_official25_context_ablation_20261117/REPRODUCE_KO.md)에 동결 입력 준비, 기존 점수 검산, 새 리뷰와 채점 명령을 정리했다. 다른 비교는 기존 실행 코드와 결과를 제공하며 별도 입력 복원이 필요하다.
